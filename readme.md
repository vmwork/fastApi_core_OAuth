# FastBlog API

[![Python](https://img.shields.io/badge/Python-white?logo=Python)](https://python.org)
[![FastAPI](https://img.shields.io/badge/FastAPI-white?logo=FastAPI)](https://fastapi.tiangolo.com)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-white?logo=PostgreSQL)](https://postgresql.org)
[![Docker](https://img.shields.io/badge/Docker-white?logo=Docker)](https://docker.com)

Современный, высокопроизводительный REST API для блогинга с продвинутой ролевой моделью доступа (**Администратор / Автор / Пользователь**). Проект полностью контейнеризирован, готов к деплою и локальной разработке с поддержкой **Hot-Reload**. Идентификаторы всех сущностей переведены на современный, безопасный и быстрый стандарт **UUID v7**.

---

## 📂 Архитектура проекта (Clean Architecture)

```text
fast-blog/
├── backend/               # Исходный код приложения
│   ├── alembic/           # Миграции базы данных (Alembic)
│   ├── apis/              # Маршрутизация (Роутеры эндпоинтов)
│   ├── core/              # Настройки, безопасность (JWT) и конфигурация
│   ├── db/                # Сессии БД и паттерн Repository (CRUD логика)
│   ├── models/            # Бизнес-сущности SQLAlchemy (User, Blog, Category)
│   ├── schemas/           # Валидация данных Pydantic (DTO модели)
│   ├── utils/             # Вспомогательные утилиты (Генератор UUID v7)
│   ├── seed.py            # Автоматический сид первоначальных данных (Админ)
│   └── main.py            # Точка входа в приложение FastAPI
├── docker-compose.yml     # Конфигурация Docker-окружения
└── Dockerfile             # Сборка оптимизированного Docker-образа
```

## 🚀 Быстрый старт & Автоматизация

Разверните всю инфраструктуру, автоматически накатите миграции и создайте суперадмина одной командой:

```bash
docker-compose build --no-cache && docker-compose up
```

> 💡 **Автономный Деплой:** При старте контейнера бэкенда автоматически отрабатывает встроенный скрипт развертывания `deploy.sh`. Он дожидается готовности СУБД, применяет миграции Alembic, а также запускает `seed.py`, который создает встроенного тестового суперадмина, если база пуста.
> * **Дефолтный Админ:** `admin@example.com` / `admin123`

Приложение будет доступно по адресу: **`http://localhost:8000`**

## 📑 Спецификация API (Эндпоинты)

### 🔐 Авторизация & Сессии

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/token` | Аутентификация пользователя и выдача JWT Bearer токена | Публичный |

### 👤 Управление пользователями & Админка

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/users` | Регистрация нового аккаунта (ID: UUID v7) | Публичный |
| `GET` | `/users` | Получить список всех пользователей системы | **Только Админ** |
| `PATCH` | `/users/{id}/toggle-active` | Заблокировать / разблокировать пользователя | **Только Админ** |

### 📰 Статьи (Блоги)

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/blogs` | Получить список только опубликованных статей | Публичный |
| `GET` | `/blogs/all` | Получить вообще все статьи приложения (включая черновики) | Публичный |
| `POST` | `/blogs` | Создать новую статью (создается как черновик) | Авторизован |
| `GET` | `/blogs/{id}` | Детальная информация о статье по UUID | Публичный |
| `PUT` | `/blogs/{id}` | Полное обновление контента статьи | **Только Автор** |
| `PATCH` | `/blogs/{id}/approve` | Одобрять публикацию статьи (перевод в `published`) | **Только Админ** |
| `DELETE`| `/blogs/{id}` | Безвозвратное удаление статьи | **Только Автор** |

### 📁 Категории

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/blogs/categories` | Получить список всех категорий | Публичный |
| `POST` | `/blogs/categories` | Создать новую рубрику (уникальный `slug`) | Авторизован |
| `GET` | `/blogs/categories/{id}` | Получить информацию о категории по UUID | Публичный |
| `PUT` | `/blogs/categories/{id}` | Обновить настройки/имя категории | Авторизован |
| `DELETE`| `/blogs/categories/{id}` | Удалить категорию из системы | Авторизован |
| `GET` | `/blogs/categories/{id}/blogs` | Получить все статьи из данной категории | Публичный |

### 🩺 Мониторинг

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/health` | Проверка жизнеспособности сервиса (Healthcheck API) | Публичный |
