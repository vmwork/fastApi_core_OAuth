# FastAuth API Core + OAuth 🔥

[![Python](https://img.shields.io/badge/Python-white?logo=Python)](https://python.org)
[![FastAPI](https://img.shields.io/badge/FastAPI-white?logo=FastAPI)](https://fastapi.tiangolo.com)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-white?logo=PostgreSQL)](https://postgresql.org)
[![Docker](https://img.shields.io/badge/Docker-white?logo=Docker)](https://docker.com)


Современное, готовое к работе ядро (Core) REST API на FastAPI с полноценной поддержкой OAuth2 авторизации, JWT-токенов и ролевой моделью доступа (**Администратор / Пользователь**). 

Проект полностью контейнеризирован, идеально подходит как шаблон (Boilerplate) для быстрого старта разработки любого микросервиса. Идентификаторы пользователей переведены на современный, безопасный и быстрый стандарт **UUID v7**.

---

## 🏗️ Архитектура проекта

```text
fastApi_core_OAuth/
└── backend/               # Исходный код приложения
    ├── alembic/           # Конфигурация и миграции базы данных (Alembic)
    ├── apis/              # Маршрутизация (Роутеры эндпоинтов авторизации и юзеров)
    ├── core/              # Настройки безопасности (JWT, OAuth2) и конфигурация
    ├── db/                # Сессии БД и базовая модель
    ├── models/            # Бизнес-сущности SQLAlchemy (User)
    ├── schemas/           # Валидация данных Pydantic (DTO модели)
    ├── utils/             # Вспомогательные утилиты (Генератор UUID v7)
    ├── seed.py            # Автоматический сид первоначальных данных (Суперадмин)
    ├── main.py            # Точка входа в приложение FastAPI
    └── deploy.sh          # Автономный скрипт развертывания внутри Docker
├── docker-compose.yml     # Конфигурация Docker-окружения
└── Dockerfile             # Инструкция сборки Docker-образа
```

## ⚡ Быстрый старт & Автоматизация

Разверните всю инфраструктуру, автоматически накатите актуальные миграции и создайте тестового суперадмина одной командой:

```bash
docker-compose up --build --force-recreate
```

> 📦 **Автономный Деплой:** При старте контейнера бэкенда автоматически отрабатывает встроенный скрипт `deploy.sh`. Он дожидается полной готовности СУБД PostgreSQL, применяет миграции Alembic, а также запускает `seed.py`, который создает встроенного администратора, если база пуста.

## 📋 Спецификация API (Эндпоинты)

### 🔑 Авторизация & Сессии

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/token` | Аутентификация пользователя и выдача JWT Bearer токена | Публичный |

### 👥 Управление пользователями & Административная панель

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/users` | Регистрация нового аккаунта (ID: UUID v7) | Публичный |
| `GET` | `/users` | Получить список всех пользователей системы | **Только Админ** |
| `PATCH` | `/users/{id}/toggle-active` | Заблокировать / разблокировать пользователя | **Только... Админ** |

### 🛠️ Мониторинг

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/health` | Проверка жизнеспособности сервиса (Healthcheck API) | Публичный |
